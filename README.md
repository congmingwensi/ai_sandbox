## 核心规则

### 1. 地图与区域属性
地图由若干“区域”（Region）组成，每个区域具有：
- **id**：唯一编号（两位数显示）
- **owner**：阵营归属  
  - `0` 中立  
  - `1` 蓝方  
  - `2` 红方
- **troops**：兵力（整数）
- **area**：地形面积（影响战斗宽度或防御加成）
- **env**：环境系数（0~1，影响战斗修正）
- **neighbors**：邻接区域 id 列表
- **pos**：地图坐标（渲染用）

### 2. 视野与情报
- **己方**：所有己方区域显示完整信息（`troops / area / env / neighbors`）。
- **中立/敌方**：  
  - 与己方相邻的区域：显示完整数值。  
  - 更远的区域：只显示 `owner`。
- 输出时会标注中立/敌方**与我方相邻的己方格 id**。

### 3. 自然事件系统
- 每回合每个区域触发 1 个随机事件，影响兵力（正/负都有可能）。  
- 占领区和邻接中立区使用不同的事件池，数值波动不同。  
- 控制台会显示**兵力增前 10**与**兵力减前 5**的事件，格式：
```
中立（仅邻接）：
id:03 T:47 env:2.06 neighbors: 02 10 | id:05 T:13 env:2.47 neighbors: 12
```

### 4. 行动类型
- **调兵**：从己方多个区域向目标己方区域输送兵力（途中会有损耗，至少保留 1 兵）。
- **进攻**：攻击邻接的非己方区域，战斗结算规则：
  - 攻守双方战斗力 = 兵力 × 环境修正 × 幸运系数（加固状态防御 ×1.5）。
  - 双方损耗按强弱比和系数计算，幸存进攻方抽取一定比例作为驻军进入目标区。
  - 进攻失败则目标守军保留幸存兵力。

### 5. 回合流程
1. 蓝方回合 → 红方回合
2. 每方依次：
   - 执行调兵（可选）
   - 执行一次进攻（若无可打赢目标则跳过）
3. 触发自然事件 → 更新地图状态
4. 重复直到回合数耗尽或一方全灭

## 运行方法

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动对战
```bash
python run_gpt_duel.py --blue heuristic --red random --rounds 50 --seed 42
```

参数说明：
- `--blue` / `--red`：蓝方/红方 AI 类型，可选：
  - `heuristic`：基于规则的 AI
  - `random`：随机 AI
  - `nano`：调用接口
  - `net`：手动问网页版AI，把json输入回去
  - （后续可扩展 `llm` 接口）
- `--rounds`：最大回合数
- `--seed`：随机种子
- `--map`：自定义地图 JSON 文件路径

### 3. 更新地图兵力（批量）
使用 `tools/gen_map_7x7.py`：
```bash
python tools/gen_map_7x7.py --update 10 20 30 ... --out data/sample_map_50.json
```
- `--out` 重新生成地图
- `--seed` 随机种子
- `--update` 后面是地图上每个区域的兵力值（数量需与地图格子数一致）。
